# Kawi AI — ผู้ช่วยแต่งโคลงสี่สุภาพ

เว็บแอปสำหรับแต่งและตรวจฉันทลักษณ์โคลงสี่สุภาพ มีผู้ช่วย AI (Gemini) ช่วยร่างโคลงจากหัวข้อที่กำหนด
และตัวตรวจฉันทลักษณ์แบบกฎตายตัว (deterministic) ที่ตรวจโครงสร้าง คำเอก-คำโท และสัมผัสแบบเรียลไทม์

Deployed: https://krulintiphat.vercel.app/

## Features

- **ผู้ช่วยทรงปัญญา (AI Assistant)** — พิมพ์หัวข้อ ระบบเรียก Gemini ผ่าน server-side API เพื่อร่างโคลง
  4 บาท แล้วตรวจ+แก้ไขซ้ำอัตโนมัติ (สูงสุด 3 ครั้ง) ก่อนส่งให้ผู้ใช้
- **แต่งโคลงด้วยตนเอง (KlongEditor)** — พิมพ์ทีละคำในช่องแยกตามตำแหน่ง ระบบตรวจให้ทันทีว่า:
  - จำนวนคำครบตามผังโคลงหรือไม่
  - ตำแหน่งบังคับเอก/โท ถูกต้องหรือไม่ (รองรับคำตายแทนคำเอก)
  - คำสัมผัสระหว่างบาทคล้องจองกันหรือไม่ (แสดงระดับความมั่นใจ: ถูกต้อง / ไม่แน่ใจ / ไม่คล้องจอง)

## Tech Stack

Vite + React 18 · Tailwind CSS · lucide-react · Vercel Serverless Functions (Node) · Vitest

## Getting Started

```bash
npm install
cp .env.example .env    # ใส่ GEMINI_API_KEY ของคุณ
npm run dev
```

เปิด http://localhost:5173 (หรือพอร์ตที่ Vite แจ้ง)

## Environment Variables

| ตัวแปร | คำอธิบาย |
|---|---|
| `GEMINI_API_KEY` | Gemini API key — ใช้ฝั่งเซิร์ฟเวอร์เท่านั้น **ห้ามใส่ prefix `VITE_`** (จะถูกฝังไปกับโค้ดฝั่ง client ทันที) |

บน Vercel ต้องตั้งค่าตัวแปรนี้แยกในหน้า Project Settings → Environment Variables ด้วย
(`.env` ไม่ถูก deploy เพราะอยู่ใน `.gitignore`)

## ฉันทลักษณ์ที่ระบบตรวจ (โคลงสี่สุภาพ)

นิยามอยู่ที่ `klongRules.js` ใช้เป็นต้นทางเดียวทั้งฝั่งพร้อมพ์ AI และตัวตรวจ:

- จำนวนคำ: บาท 1-3 บาทละ 7 คำ (5+2), บาท 4 = 9 คำ (5+4)
- ตำแหน่งคำเอก: บาท1 คำ4 / บาท2 คำ2,6 / บาท3 คำ3,7 / บาท4 คำ2,6
- ตำแหน่งคำโท: บาท1 คำ5 / บาท2 คำ7 / บาท3 ไม่มี / บาท4 คำ5,7
- สัมผัสระหว่างบท: (บาท1 คำ7)-(บาท2 คำ5)-(บาท3 คำ5) และ (บาท2 คำ7)-(บาท4 คำ5)
- คำตายใช้แทนตำแหน่งเอกได้

ตำแหน่งเหล่านี้ตรวจสอบแล้วกับตัวอย่างที่ยืนยันได้ ("เสียงลือเสียงเล่าอ้าง อันใด" — เล่า/คำ4 มีไม้เอก, อ้าง/คำ5 มีไม้โท)

## Known Limitations

- **สัมผัสสระ** ตรวจด้วยฮิวริสติก (เทียบสระ+ชนิดตัวสะกด) ไม่ใช่การวิเคราะห์เสียงเต็มรูปแบบ —
  กรณีไม่แน่ใจจะแสดงเป็นคำเตือน ไม่ใช่ข้อผิดพลาด
- **คำสร้อย** ท้ายบาท 1 และ 3 ยังไม่รองรับการตรวจ
- **เอกโทษ/โทโทษ** (คำผันเสียงพิเศษแทนเอก-โท) ยังไม่รองรับ
- Gemini เรียกแบบปิด extended thinking เพื่อความเร็ว (ดูเหตุผลใน `CLAUDE.md`) — ทำให้บางครั้ง AI
  ร่างโคลงไม่ผ่านฉันทลักษณ์ครบ 100% ในครั้งแรก ต้องแก้ไขต่อในตัวแก้ไขเอง
